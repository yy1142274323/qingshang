# 清商音乐播放器 v1.0.0

一个 128 KB 的 Windows 本地音乐播放器。界面全部用 GDI+ 手绘，音频走系统自带 MCI，不依赖任何第三方库。

## 下载哪个？

两个文件装的是同一个程序，功能完全一样，挑顺手的：

| 文件 | 大小 | 适合谁 |
| --- | --- | --- |
| **QingShang.exe** | 128 KB | **便携版**。绿色单文件，双击即用，不写注册表，扔 U 盘里就能带走 |
| **QingShang-Setup-1.0.0.exe** | 2.0 MB | **安装版**。多出开始菜单、桌面快捷方式、卸载入口，适合发给不折腾的人 |

> 需要 .NET Framework 4.8。Win10 1803 以后的系统自带；Win7 / 8 需要先装一次。

## 这一版有什么

**播放**

- 拖放文件或文件夹即可加载，子目录递归扫描
- 支持 `.m3u` / `.m3u8` / `.pls` 播放列表，任何工具导出的歌单拖进来就整批导入
- 上一首 / 播放暂停 / 下一首，空格键和键盘媒体键都能控制
- 四种播放模式：列表循环、单曲循环、随机、顺序播放
- 进度条拖动定位，音量条带静音
- 双击列表项播放，右键可移除或在资源管理器里定位

**显示**

- 黑胶唱片随播放旋转，配色按曲目信息哈希生成，每首歌都不一样
- 56 段频谱柱随机律动
- LRC 歌词滚动高亮，当前行居中放大
- 读 ID3v2 / ID3v1 标签，读不到就用文件名兜底
- 列表直接显示时长：WAV 读 RIFF 头，MP3 按首帧比特率估算
- 无边框圆角窗口，双击标题栏切迷你模式（470×108）
- 100% / 125% / 150% 缩放都不错位

**快捷键**

| 键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` `→` | 后退 / 前进 5 秒 |
| `↑` `↓` | 音量 ±5% |
| `Esc` | 退出迷你模式 |

**命令行**

```
QingShang.exe "D:\Music"          直接加载整个目录
QingShang.exe "playlist.m3u8"     加载播放列表
QingShang.exe --mini              启动即迷你模式
```

## 没有歌怎么办

播放器不带任何内容。仓库里带了个脚本，可以从 Internet Archive 批量拉 CC 授权 / 公共领域的音乐并生成歌单：

```powershell
.\tools\get-free-music.ps1                 # 默认 40 首
.\tools\get-free-music.ps1 -Count 200
.\tools\get-free-music.ps1 -Collection musopen -OutDir classical
```

## 已知边界

- 不自带解码器，flac / m4a 能不能放取决于系统
- 没有内嵌封面图提取，唱片用的是哈希生成的渐变色
- 频谱是合成的节奏可视化，不是真实 FFT
